# 📋 Task Board — Quadro Kanban Pessoal

Quadro Kanban web para organizar tarefas: arrastar e soltar entre colunas, prioridades, tags, prazos e resumo de produtividade. 100% client-side, sem backend.

## Recursos

- 🗂️ **3 colunas** — A Fazer | Fazendo | Concluído
- 🖱️ **Drag & Drop** — mover cards entre colunas (HTML5 Drag API)
- 🔴🟡🟢 **Prioridades** — urgente, alta, média, baixa com cores
- 🏷️ **Tags** — categorize tarefas livremente
- 📅 **Prazos** — data limite com indicador visual de atraso
- 🔍 **Filtros** — por tag, prioridade, prazo e busca por texto
- 📊 **Resumo** — contador por coluna, atrasadas, concluídas na semana
- 💾 **Offline** — dados salvos no navegador (localStorage)
- 🌙 **Tema escuro** nativo
- 📱 **Responsivo** — celular, tablet e desktop

## Tech Stack

- HTML5 (Drag and Drop API) + CSS3 + JavaScript vanilla
- Canvas API para mini gráficos
- localStorage (prefixo `tb_`)

## Como usar

Abra `index.html` no navegador. Pronto.
